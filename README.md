Gestor Restaurante

Proyecto en Python para gestionar pedidos,facturacion y operaciones básicas de un restaurante.

## Funcionalidades
- Menú interactivo
- Gestión de pedidos
- Calculo de totales
- Generacion de recibos
- Uso de estructuras de control y funciones

## Cómo ejecutar
python gestor_restaurante.py
